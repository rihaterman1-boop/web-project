# GitStart — учебный справочник по Git и GitHub

Сайт для начинающих: объясняет, зачем нужен Git, и собирает основные команды.

## Страницы
- `index.html` — главная: три блока (зачем Git, что даёт GitHub, для кого сайт).
- `commands.html` — основные команды: первый коммит, ветки, просмотр истории.

## Технологии
HTML5, CSS3 (Flexbox, Grid, медиазапросы), Git, GitHub, GitHub Pages.

## Запуск локально
```bash
git clone https://github.com/USERNAME/web-project.git
cd web-project
# откройте index.html в браузере
```
