Учебный справочник по Git и GitHub

Короткие объяснения и команды для тех, кто делает свой первый проект с историей версий.

Зачем нужен Git

Git сохраняет историю проекта в виде коммитов. Вместо файлов «сайт_новый_2» у вас одна папка и понятный журнал изменений.

Что даёт GitHub

GitHub хранит удалённую копию репозитория, позволяет предлагать изменения через Pull Request и публиковать сайт через GitHub Pages.

Для кого справочник

Для студентов и начинающих разработчиков, которые учатся работать с ветками и объединять изменения. Готовые команды — на странице «Команды».
