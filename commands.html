Основные команды Git

Подборка команд, которые нужны в каждой лабораторной работе.

Первый коммит

git init -b main
git add .
git commit -m "Создана начальная версия сайта"

Создаём репозиторий, добавляем файлы в индекс и сохраняем первую версию.

Работа с ветками

git switch -c feature/new-page
git branch
git push -u origin feature/new-page

Новая ветка позволяет менять проект, не затрагивая рабочую версию в main.

Просмотр истории

git status
git log --oneline --graph --all
git diff

Помогают понять, что изменилось и когда.
